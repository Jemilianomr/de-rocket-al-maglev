# De Rocket al Maglev

Atlas 3D interactivo de la evolución de la tracción ferroviaria entre 1829 y 2004, pensado para ingenieros mecánicos y eléctricos. Ocho hitos modelados a escala 1:1 en Three.js, con piezas seleccionables, cortes de sección, vista explosionada, rayos X, flujos de energía, fichas técnicas, ecuaciones con datos reales, contexto histórico y fuentes.

**Demo:** https://jemilianomr.github.io/de-rocket-al-maglev/

```sh
python3 build.py   # genera docs/index.html (GitHub Pages) y dist/
```
